# Emsworth Pro Tech — Pro Nanotechnology

A static, mobile-friendly website for Emsworth Pro Tech. It uses HTML, CSS, and JavaScript only. There is no build step, server-side code, or database.

## Pages

- Home
- Services (nine service cards)
- About
- Projects (example project concepts)
- Team
- Contact

## Run locally

Open `index.html` in a browser. The service photos are stored locally in `assets/images`, so the cards do not hotlink image files. Google Fonts is optional; local system-font fallbacks are included.

## Publish with GitHub Pages

1. Create a GitHub repository and add these files at its root.
2. Push the default branch (usually `main`).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Open the Pages URL shown by GitHub after deployment finishes.
